Quotes Parser
Парсинг цитат с сайта quotes.toscrape.com
Что делает скрипт

Проходит по всем страницам сайта и собирает:
Текст цитаты
Автора
Теги (ключевые слова)
Все данные сохраняются в Excel-файл quotes.xlsx.

Как работает
Загружает первую страницу сайта
Находит все цитаты на странице
Извлекает текст, автора и теги
Переходит на следующую страницу (если есть)
Повторяет, пока страницы не закончатся
Сохраняет результат в Excel
Запуск
python quotes_parser.py

Результат
Файл quotes.xlsx с тремя колонками: Автор, Цитата, Теги
Пример строки: Альберт Эйнштейн | The world is a book... | inspirational, life
Технологии
requests для загрузки страниц
BeautifulSoup4 для парсинга HTML
openpyxl для создания Excel
time для задержки между запросами

Важно
Скрипт использует задержку 1 секунду между запросами, чтобы не нагружать сервер.
